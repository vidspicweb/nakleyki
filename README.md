# Наклейки на тетради

Программа сама вписывает в PDF-шаблоны наклеек класс, школу, фамилию и имя ученика
(«ученика / ученицы», нужный падеж — автоматически).

## Как пользоваться

1. Откройте файл **`Наклейки.html`** двойным щелчком — лучше в **Google Chrome**, **Яндекс Браузере** или **Edge**
   (только в них видны все шрифты компьютера). Интернет не нужен.
2. **Ученики** — добавьте класс и вставьте список (каждый ученик с новой строки: «Фамилия Имя»).
   Строки, отмеченные жёлтым, проверьте: программа не уверена в поле (Саша, Женя…).
3. **Шаблоны** — перетащите PDF с наклейками. Каждая страница станет шаблоном.
4. **Настройка** — передвиньте строки мышкой на одной наклейке, выберите шрифт и размер.
   Все остальные наклейки выровняются так же.
5. **Печать** — выберите класс и шаблоны → «Создать PDF». При печати ставьте масштаб **100%**.

Данные хранятся только в браузере на этом компьютере. Время от времени делайте
резервную копию: ⚙ → «Сохранить копию в файл».

## Для разработки

```bash
npm install
npm run dev                 # режим разработки
SINGLE=1 npx vite build     # собрать всё в один файл dist/index.html
```

Стек: React + TypeScript + Vite, pdf.js (показ PDF), pdf-lib (сборка PDF), lvovich (склонение ФИО).
Основные файлы: `src/names.ts` (пол и падеж), `src/pdf.ts` (поиск сетки наклеек),
`src/render.ts` (рисование текста), `src/export.ts` (создание PDF), `src/pages/*` (экраны).
